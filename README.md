Entry for the make.fun competition **Your AI Therapist's Diagnosis**
(`u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41`): write the funniest
single-line diagnosis an AI therapist hands its human, 200 characters or less.

`main.ts` writes the entry — one deadpan clinical diagnosis of a very human
habit, with the twist landing in the final words — to `/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

The entry line (164 characters):

> Diagnosis: chronic 2 a.m. re-reading of old chats, complicated by apologising to me for things you did to yourself. Prescription: sleep, then apologise to yourself.
